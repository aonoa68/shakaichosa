## この回の問い

> 国が集めたデータを、私たちはどこまで自由に使えるのか。

## 到達目標

1. **1次データと2次データ**を区別し、今日使うのがどちらかを言える
2. 公的統計の定義と種類（基幹統計・一般統計・業務統計）を説明できる
3. 日本の統計機構が**分散型**であることと、それが統計の探し方に与える影響を説明できる
4. 国勢調査の目的・方法・活用方法を理解する
5. 政府・報道機関の世論調査の違いと限界を把握する
6. **e-Stat** を実際に操作して、関心のある統計データを検索・ダウンロードできる
7. 2次データを使う前に**確認すべき4点**を挙げられる

## 要点

### まず用語 ―― 1次データと2次データ

今日使うのは、全部**2次データ**である。

| | 定義 | 例 |
|---|---|---|
| **1次データ** | 調査目的を決めたうえで、**その目的に合うように自分で集めた**データ | 第11回で自分が作るアンケート、第12回のインタビュー記録 |
| **2次データ** | 調査目的を決めたとき、**すでに公開されていた**データ | 国勢調査、家計調査、各省庁の統計 |

2次データは、他人が**別の目的で**集めたものである。ここが落とし穴の出どころになる。

!!! note "「二次分析」という言い方"
    2次データを使って分析することを**二次分析**（secondary analysis）と呼ぶ。
    手元にお金も時間もない学生の調査では、**まず二次分析で足りないかを考える**のが筋である。
    すでに国が全数で調べているものを、学生が100人に聞いて確かめ直す意味はあまりない。

    自分で集める（1次データ）のは、**既存のデータでは答えられない問い**のときである。
    第4回で「目的に方法を合わせる」と言ったのは、ここにもかかっている。

### 公的統計とは

公的統計は**統計法**にもとづいて作成される統計であり、3つに分類される。

| 種類 | 位置づけ | 例 |
|---|---|---|
| **基幹統計** | 特に重要なものとして総務大臣が指定 | 国勢調査、労働力調査、家計調査 など |
| **一般統計** | 行政機関が作成するその他の統計 | 各種実態調査 |
| **業務統計** | 業務上の記録を集計したもの | 人口動態統計（出生届・死亡届から） |

基幹統計は報告義務があり、精度が高い一方で、業務統計は「届け出があったもの」しか映らないという性格を持つ。**どう作られた数字なのかで、読み方が変わる。**

### 日本の統計機構は「分散型」である

これは制度の話に見えて、**統計の探し方に直接ひびく**。

| | 仕組み | 例 |
|---|---|---|
| **分散型** | 中心となる統計機関と、各府省がそれぞれ所管分野の統計を作る | **日本** |
| **集中型** | ひとつの統計機関が集中して作る | カナダ（カナダ統計局）、オーストラリア（ABS）など |

総務省の説明はこうである。

> 我が国の統計機構は、総務省統計局が国勢の基本に関する統計を作成し、各府省が所管行政と密接に関連する統計を作成する**分散型統計機構**です。
>
> 分散型統計機構においては、各行政機関が作成する統計を**横断的に調整する機関**が必要となり、その機能は**総務省政策統括官（統計制度担当）**が担っています。

!!! tip "だから e-Stat が必要になる"
    分散型だと、統計が**作っている省庁ごとにばらばらの場所に置かれる**。
    労働の統計は厚生労働省、農業は農林水産省、貿易は財務省、というように。

    - **探すとき** … 「どの省庁の仕事か」を考えないと見つからない。それを一箇所にまとめたのが **e-Stat**
    - **比べるとき** … 省庁が違えば、調査時期・集計単位・用語の定義が違うことがある。
      「世帯」「失業者」「事業所」の定義が統計によって違うのは、この構造の帰結でもある
    - **だから調整が必要** … 政策統括官（統計制度担当）が、統計関係法令、基本計画、
      各府省の統計調査の審査・承認、**日本標準産業分類などの統計基準**を担っている

    集中型の国なら、ひとつの機関が定義をそろえて作る。
    **どちらが良いという話ではなく、日本の統計はこういう形で作られている**と知っておくこと。

### 国勢調査（Census）

- **実施主体**：総務省統計局
- **周期**：5年に1回（直近2025年）
- **対象**：日本に住むすべての人・世帯 ＝ **全数調査**
- **調査事項**：氏名・年齢・住所・職業・世帯構成など
- **用途**：人口推計、選挙区割り、地方交付税の算定、防災計画などの基礎データ

日本の国勢調査は1920年（大正9年）に始まり、100年以上続いている。**行政のあらゆる計算の土台**になっているため、ここが狂うと下流の全部が狂う。

### 世論調査 ―― 誰が実施したかで別物になる

| | 内閣府（政府） | NHK・新聞社 |
|---|---|---|
| 目的 | 政策への支持・国民意識の把握 | 報道・世論の可視化 |
| 方法 | 無作為抽出＋調査員による面接が中心 | 電話（RDD）・郵送・Webなど多様 |
| 公開水準 | 調査票・標本設計まで公開 | 概要中心のことが多い |
| 頻度 | テーマごとに随時 | 毎月など高頻度 |

**限界と批判**：質問文の言い回しで結果が動く（→ 第11回）、電話調査では固定電話の有無で偏る、回答率の低下が続いている、内閣支持率のように**同じ月でも社数によって数字が違う**。数字だけでなく、**誰がどう聞いたか**まで見る必要がある。

### e-Stat（政府統計の総合窓口）

<https://www.e-stat.go.jp/> で、各省庁の統計を横断的に検索・ダウンロードできる。無料・登録不要。

- **総務省統計局が整備**し、**独立行政法人統計センター**が運用管理している
- **2008年**から本運用
- **データ検索** … 分野別／機関別／調査名から絞り込む
- **統計ダッシュボード**（<https://dashboard.e-stat.go.jp/>）… 主要指標をグラフで確認する
- ダウンロード形式は CSV・Excel。**そのまま分析に使える**

### 地域で見るなら ―― RESAS

<https://resas.go.jp/>（地域経済分析システム）は、人口動態・産業構造・人の流れなどを**地図やグラフで可視化**できるシステムである。

- **2015年4月**に提供開始。経済産業省と内閣官房・内閣府が提供
- 人口マップ、産業構造マップ、まちづくりマップなど、テーマ別に地域を比較できる
- **旧システムは2025年3月6日に運用終了**し、翌3月7日から新システムに切り替わった（2026年6月にも更新）

地域を単位にした問いを立てるなら、e-Stat で表を探す前に RESAS で地図を見ると早いことがある。

!!! danger "統計サイトは数年で終わる ―― これは今日いちばん実用的な注意点"
    統計の解説記事や授業資料に出てくるサイトは、**数年で終了したり移行したりする**。
    この回で挙げたものだけでも、直近でこれだけ動いている。

    | サービス | 何が起きたか |
    |---|---|
    | **V-RESAS** | コロナ禍の地域経済を見るために作られたが、**2024年3月1日にサイト公開を終了**。[RAIDA（地方創生データ分析評価プラットフォーム）](https://raida.go.jp/)に移行した |
    | **RESAS API** | **2024年10月1日に新規登録を停止**し、サービス終了 |
    | **RESAS 本体** | **2025年3月6日に旧システムが運用終了**、翌日から新システム |

    つまり、**2022年に書かれた解説をそのまま信じると、存在しないサイトを探すことになる。**
    （V-RESAS は現在、ドメイン自体が引けない。）

    レポートや課題で統計サイトを引くときは、

    1. **自分でアクセスして、生きているか確かめる**
    2. **アクセスした日付を書く**（「2026年10月8日閲覧」）
    3. 解説ページではなく、**提供元の公式ページ**を典拠にする

    これは第8回（資料・文献調査）でもう一度扱う。

### 2次データを使う前に確認する4点

2次データは**他人が別の目的で集めたもの**なので、自分の問いに合うかどうかは保証されていない。
使う前に、最低この4つを調査の概要ページで確認する。

| 確認すること | なぜ |
|---|---|
| **① 収集時期** | いつ時点のデータか。最新公表が3年前、ということは普通にある |
| **② 収集方法** | 全数か標本か、誰にどう聞いたか（→ 第10回・第11回） |
| **③ 調査主体** | 誰が作ったか。省庁・業界団体・企業で、目的も中立性も違う |
| **④ 利用の可否と範囲** | 利用規約・出典表示の条件。**ゼミ発表と公開レポートで条件が違うことがある** |

!!! warning "「完璧に合うデータ」は存在しないのが普通"
    自分の問いにぴったり合う2次データは、たいてい見つからない。
    そこで取れる道は3つある。

    - **問いを、あるデータで答えられる形に調整する**
    - **近いデータで答え、ずれを明記する**（これが誠実な書き方）
    - **自分で集める**（1次データ。ただし時間とお金がかかる）

    **「データがなかったので推測しました」は3つのどれでもない。**

### 公的統計を使うときの落とし穴

1. **定義の変更** … 「失業者」「世帯」などの定義は改定されることがある。年をまたぐ比較の前に定義を確認する
2. **比較可能性** … 調査方法が変わった年をまたぐと、変化が実態なのか方法の変化なのか分からなくなる
3. **集計単位** … 市町村合併により、地域の時系列が連続しないことがある
4. **府省による定義の違い** … 分散型なので、同じ言葉が統計によって別の定義を持つことがある

!!! note "教室での演習"
    e-Stat にアクセスし、関心のあるテーマの統計を1つ探して、実際にデータを表示するところまでやってみる。

## 今日の課題（Moodle提出）

**配点**：100点（この授業の評価は毎回の課題100%）　／　**提出期限**：次回授業の開始前まで

**分量**：300〜500字程度

e-Stat（<https://www.e-stat.go.jp/>）にアクセスし、**自分が関心を持つ社会的テーマに関連する統計データを1つ見つけ**、以下の点を述べること。

1. **統計名・実施機関・最新の調査年**（＝確認4点の①と③）
2. その統計が**何を明らかにしようとしているか**（目的・調査対象の説明）
3. データを実際に見て、**気づいたこと・読み取れた傾向**を1〜2点
4. この統計データを用いて**どのような研究・分析が可能か**、自分自身のアイデア

スクリーンショットや図表の添付は任意。初めて e-Stat を使った場合は、操作してみた感想も一言添えること。

!!! tip "1で「実施機関」を必ず書く理由"
    日本の統計は**分散型**なので、同じテーマでも作っている省庁が違えば定義や集計単位が違います。
    実施機関を書くことは、**そのデータの素性を押さえる**ということです。

    また、**URLとアクセス日**（「2026年10月27日閲覧」など）も添えてください。
    統計サイトは数年で移行するので、これがないと後から誰も確かめられなくなります。

## この回のまとめ

- **1次データ**は自分で集めたもの、**2次データ**はすでに公開されていたもの。今日扱ったのは全部2次データ
- 既存データで答えられる問いは、**まず二次分析**を考える
- 公的統計は統計法に基づき、**基幹統計・一般統計・業務統計**に分類される
- 日本の統計機構は**分散型**（総務省統計局＋各府省）。だから横断的に調整する**総務省政策統括官（統計制度担当）**があり、だから **e-Stat** が必要になる
- **国勢調査**は5年周期の全数調査で、政策・研究の基盤データ
- 世論調査には政府実施と報道機関実施があり、目的・方法・公開水準が異なる
- 2次データを使う前に **①収集時期 ②収集方法 ③調査主体 ④利用の可否と範囲** を確認する
- 統計を使う際は**定義の変更・比較可能性・集計単位・府省による定義の違い**に注意する
- **統計サイトは数年で終了・移行する**（V-RESASは2024年3月に終了）。自分でアクセスして確かめ、閲覧日を書く

    URL: https://raida.go.jp/
    → 内閣府地方創生推進室・内閣官房地域未来戦略本部事務局が提供。
    **2024年3月に公開を終了した V-RESAS の後継**にあたる。人口減少対策・観光振興などのテーマ別に分析できる。

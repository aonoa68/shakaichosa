## この回の問い

> 調査は何から始めて、どう終わるのか。そして「やってはいけない調査」とは、どういうものか。

## 到達目標

1. 社会調査の一般的な手順（ステップ）を説明でき、**分析と解釈を区別できる**
2. 各ステップにおける主な注意点を挙げられる
3. 社会調査倫理の基本原則（インフォームドコンセント等）を理解し、**同意の取り方が一通りでないことを説明できる**
4. 過去の倫理的問題事例から、なぜ倫理が重要かを説明できる
5. IRB（研究倫理審査）の仕組みと意義、**および適用範囲が分野・機関によって違うこと**を把握する
6. 具体的な調査計画について、**問題点 → 生じるリスク → 改善策 → 残る限界**の順で検討できる

## 要点

### 調査の全体の流れ

社会調査は次の6ステップで進む。ただし一直線ではなく、**行きつ戻りつする反復的なプロセス**である。

| ステップ | やること | 注意点 |
|---|---|---|
| ① 問い・仮説の設定 | 何を明らかにしたいのかを言葉にする | 漠然としたテーマを、答えられる問いに絞る |
| ② 調査設計 | 対象・方法・時期を決める | 目的に方法を合わせる（→ 第4回） |
| ③ データ収集 | 実際に集める | 倫理的手続きはここより**前**に済ませる |
| ④ 分析 | データを整理し、集計・検定する | 何を見るかは、手を動かす前に決めておく |
| ⑤ 解釈 | 分析結果が何を意味するかを述べる | **分析から言えること／言えないこと**を分ける |
| ⑥ 報告・公開 | 結果を共有する | 手順を明示し、再現できる形で書く |

!!! note "④と⑤はひとつの作業ではない"
    「平均が3点上がった」は**分析**の結果である。「だから施策に効果があった」は**解釈**である。
    この2つを区切らずに書くと、データが言っていないことまでデータのせいにできてしまう。
    報告を読む側は、どこまでが計算でどこからが読みなのかを知りたい。だから書く側も分けておく。

### 社会調査で特に重要な3つの実務原則

社会調査は他人の生活に立ち入る行為である。だから**始める前に**守るべき原則がある。
実務でとくに問題になるのは次の3つである。

**① インフォームドコンセント**
調査の目的・方法・所要時間・データの扱いを説明し、理解したうえで同意を得る。「説明した」だけでも「同意を取った」だけでも足りない。**説明にもとづく同意**であることが要件である。

同意の取り方は書面（同意書）に限らない。日本社会学会の研究指針は「原則として事前の説明を**書面または口頭で**行い、同意を得る必要があります」としており、署名をもらう必要があるかどうかは調査の性質に応じて検討する、という立て方になっている。質問紙の冒頭に説明を置き、回答の送信をもって同意とみなす方法もある。**どの方法が適切かは、リスクの大きさ・調査手法・所属機関の規程で決まる。**

**② プライバシーと匿名性**
個人が特定されない形でデータを扱う。ここで2つの言葉を区別しておく。

| | 意味 | 典型例 |
|---|---|---|
| **匿名性**（anonymity） | **研究者にも**誰が回答したか分からない | 無記名の質問紙・Webフォーム |
| **秘密保持**（confidentiality） | 研究者は分かっているが、外には出さない・適切に守る | インタビュー、追跡調査 |

インタビュー調査で「匿名です」と言うのは、多くの場合は正確ではない。研究者は相手を知っている。約束しているのは秘密保持のほうである。

そして、**匿名化はプライバシー保護と同じではない**。氏名を消せば済むわけではなく、所属・年齢・地域・役職などを組み合わせれば特定できてしまうことがある（**再識別**）。「仮名にしても容易に特定される場合もある」ことは、日本社会学会の研究指針にも書かれている。

**③ 自発的参加**
参加は自由であり、**途中でやめる自由**も含む。断ったことで不利益を受けないと保証されていなければ、それは自発的な参加とは言えない。

!!! warning "「倫理の三原則」と混ぜないこと"
    上の3つは、**社会調査の実務でとくに問題になりやすい論点**を並べたものである。
    研究倫理の教科書に出てくる「**ベルモント・レポートの三原則**」とは別のものなので、混同しないでほしい。

    - ベルモント・レポート（1979）の三原則 … **人格の尊重**（respect for persons）・**善行**（beneficence）・**公正**（justice）
    - 上の①〜③ … それを社会調査の現場で実行するための手続き

    また、**③自発的参加は①インフォームドコンセントが成り立つための条件**でもある。
    強制されたうえでの「同意」は、説明があってもインフォームドコンセントにならない。
    3つは並列というより、原則（ベルモント）→手続き（IC）→その成立条件（自発性・匿名性）という入れ子になっている。

### なぜ原則が必要になったのか ―― 2つの教訓

**タスキギー梅毒研究**（米国、1932〜1972）
アフリカ系アメリカ人男性を対象に、梅毒の経過を観察するため**治療可能になった後も治療を与えずに放置した**。インフォームドコンセントの不在、脆弱な立場の人々の搾取という点で、研究倫理の歴史を変えた事件である。

40年続いたこの研究が止まったのは、研究の内部からの告発がきっかけだった。公衆衛生局の職員 Peter Buxtun が1960年代から疑問を提起し続け、**1972年に報道機関に情報を渡したことで問題が公になり、同年に研究は中止された**。倫理の仕組みが自動的に働いたのではなく、誰かが声を上げるまで止まらなかった、という点も含めて教訓である。その後、1974年の国家研究法、1979年の**ベルモント・レポート**、IRB制度の整備へとつながった。

!!! example "原典を見る ―― タスキギー研究"
    - [CDC: The U.S. Public Health Service Untreated Syphilis Study at Tuskegee](https://www.cdc.gov/tuskegee/about/index.html)（米国CDCによる公式の経緯説明）
    - [CDC: Timeline](https://www.cdc.gov/tuskegee/timeline.htm)（1932年から現在までの年表）

**スタンフォード監獄実験**（1971）
学生を看守役と囚人役に割り当てた実験が、参加者に深刻な心理的損害を与えて中止された。**参加者に予見される害**と、実験者自身が状況に巻き込まれる問題を突きつけた。

!!! warning "この実験は「結果」のほうも疑われている"
    よく語られるのは「ふつうの学生が、役割を与えられただけで急速に暴力的になった」という筋書きである。
    しかし、近年の資料調査はこの筋書き自体に疑問を投げている。
    Le Texier（2019）は、Zimbardo らの未公開資料を調べ、**看守役に対して実験者側から振る舞いの指示が出ていたこと**、
    一部の参加者の反応が演技であったこと、データの収集と報告が仮説に有利な方向に偏っていたことなどを指摘した。

    - 出典：Le Texier, T. (2019) "Debunking the Stanford Prison Experiment," *American Psychologist*, 74(7), 823–839.

    つまりこの実験は、**倫理の問題（参加者を傷つけた）と、方法の問題（結論が元データに支えられていない）の両方**を抱えている。
    倫理の教材として扱う価値は変わらないが、「役割が人を変えることの証明」として引用するのは適切ではない。
    授業では**前者の教材**として使う。

> どちらも「知識を得るためなら何をしてもよいわけではない」ことを示している。倫理は研究の邪魔をする制約ではなく、**研究を成り立たせる条件**である。

### IRB（研究倫理審査）―― 制度としての審査と、調査の倫理は別のこと

現在は、研究を**開始する前に**第三者が倫理的妥当性を審査する仕組み（IRB＝機関審査委員会、日本では「研究倫理委員会」など）が整備されている。「あとから謝る」ことができない領域だ、という理解が要る。

ただし、**どの研究に審査が必要かは分野と所属機関によって違う**。

| | 倫理審査の位置づけ |
|---|---|
| 医学・生命科学系 | 国の指針（人を対象とする生命科学・医学系研究に関する倫理指針）により、**審査が必須** |
| 社会学・社会調査 | 分野全体として必須とはされていない。**所属機関の規程で決まる** |

日本社会学会の研究指針は、倫理審査委員会について「主に医学・生命科学分野で発展してきた仕組みであり、社会学分野での調査・研究に対する有用性についての見解は定まっていません」と述べ、**この研究指針は倫理審査を必須とはしていない**と明記している。

!!! danger "「審査が要らない」は「倫理を考えなくてよい」ではない"
    ここで区別してほしいのは次の2つである。

    - **制度としての倫理審査** … 委員会に申請して承認を得る手続き。必要かどうかは分野・機関で決まる
    - **調査の倫理** … 誰にどう説明し、何を集め、どう守るか。**審査の有無に関係なく、調査する人の責任**

    審査がないほうが、むしろ自分で判断しなければならない。実際の手順としては、
    **①所属機関（大学・学部・研究科）の規程を確認する → ②必要な審査があれば着手前に受ける → ③審査が不要でも学会の倫理綱領・研究指針に沿って設計する**、
    という順で考える。

### 脆弱な立場にある人々への配慮

子ども、高齢者、障害のある人、被災者、生活困窮者、在留資格の不安定な人 ―― **断りにくい立場にある人**が対象になるとき、通常の手続きでは自発性が担保されない。誰が声をかけるか、どこで聞くか、断る選択肢が実際に取れるかまで設計する必要がある。

## 今日の課題（Moodle提出）

**配点**：100点（この授業の評価は毎回の課題100%）　／　**提出期限**：次回授業の開始前まで

次のシナリオについて **300〜500字程度**でまとめて提出すること。

> **「以下の調査シナリオについて、どのような倫理的問題が含まれているかを指摘し、あなたならどのように改善するかを具体的に提案しなさい。」**

**【シナリオ】**

あるNPOのスタッフが、支援している生活困窮者（20名）の実態を調査したいと考えた。支援の場（食料配布イベント）で参加者に「よかったら答えてください」と声をかけ、氏名・世帯収入・家族構成を記入する紙の調査票を配布した。回収した調査票は事務所の共有フォルダ（パスワードなし）に保存し、ボランティアスタッフも閲覧できる状態にした。

**書き方 ―― 次の4段階で書くこと（この順で採点します）**

| 段階 | 書くこと |
|---|---|
| ① 問題点の特定 | どの手続きが、どの原則に照らして問題なのか |
| ② リスクの経路 | **それによって、誰に、どんな不利益が、どう生じるのか** |
| ③ 改善策 | 実施可能な代替手続き（NPOの体力で実行できる範囲で） |
| ④ 残る限界 | 改善しても残ってしまう問題 |

!!! tip "②が今回いちばん大事です"
    「氏名を集めている」ことが、それだけで倫理違反なのではありません。
    問われるのは、**氏名が目的のために必要か／誰がアクセスできるか／本人はどの利用に同意したか**です。

    たとえば「氏名を集めた」だけなら手続きの問題にとどまりますが、
    **支援を受けている人の氏名と世帯収入が、支援を決める立場のボランティアから見える**状態になると、
    「正直に答えたら支援に影響するかもしれない」という圧力が発生します。
    ここまで書けると②になります。「プライバシーの侵害です」で止まると①のままです。

- 改善案は「**実施可能な**」ものを提案すること（「専任の研究者を雇う」は答えになりません）
- 「倫理的問題がない完璧な調査」は存在しないことも念頭に置くこと
- ④では、**この20名から分かったことが生活困窮者全体に当てはまるとは限らない**という調査設計の限界まで書けると、さらに良い答案になります（第4回以降の内容につながります）

## この回のまとめ

- 社会調査は「問い→設計→収集→**分析**→**解釈**→報告」という**反復的ステップ**で進む。分析と解釈は別の作業
- 実務でとくに重要なのは**インフォームドコンセント・匿名性／秘密保持・自発的参加**の3点。ベルモント・レポートの三原則（人格の尊重・善行・公正）とは別のもの
- 同意の取り方は**書面に限らない**。リスクと調査手法、所属機関の規程で決まる
- 匿名化とプライバシー保護は同じではない（**再識別**の問題が残る）
- タスキギー・スタンフォード監獄実験は「なぜ倫理が必要か」を示す歴史的教訓。ただし監獄実験は**結果の妥当性そのものも批判されている**
- **IRB**は研究開始前に倫理的妥当性を審査する仕組み。社会学では必須ではなく、**所属機関の規程を確認する**
- 脆弱な立場にある人への**特別な配慮**が不可欠

次回は「**社会調査の目的と分類**」を扱います。調査を**目的**（記述・説明・探索・評価）と**時間軸**（横断的・縦断的）の2軸で整理します。

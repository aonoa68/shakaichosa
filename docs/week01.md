## 要点

### 社会調査とは何か

社会調査（Social Research / Social Survey）とは、**社会的な事実や人々の意識・行動を、系統的な方法で収集・分析し、社会の実態を明らかにしようとする活動**である。鍵になる言葉は3つ。

| 言葉 | 意味するところ |
|---|---|
| 系統的（systematic） | 思いつきで集めない。手順を決めてから集める |
| データ（data） | 問いに答える根拠として、一定の方法で収集・記録した情報。数値だけでなく、意見や感情についての回答、語り、観察記録も含む |
| 調べる対象 | 人々の意識や行動、人と人との関係、制度や生活環境など、社会について確かめたい事柄 |

!!! warning "「主観はデータにならない」ではない"
    満足度、不安、支持・不支持といった**主観的な回答そのものが、社会調査の立派なデータ**である。
    避けたいのは回答者の主観ではなく、**調べる側の思い込みを、そのまま結論にしてしまうこと**のほうだ。
    だから手順を決めてから集める。

### 「なんとなく」との違いは、根拠と手続きを示せることにある

| 観点 | 個人的な印象にとどまる判断 | 系統的な社会調査 |
|---|---|---|
| 根拠 | 経験や記憶に依存しやすい | 収集・記録した情報を根拠として示す |
| 対象 | 身近な人や目立つ事例に偏りやすい | 目的に応じて対象と選び方を検討する |
| 手続き | 判断に至る過程が明示されないことが多い | 収集・分析の手続きを記録し、説明する |
| 誤りや限界の検討 | 根拠が共有されないと検討しにくい | 対象・方法・分析をもとに検討できる |

決定的なのは最後の2行だ。**誰を対象に、何を、どのように集め、どう分析したのかが明示されているから、結論を支える根拠も、その調査の限界も、他の人が検討できる。** 社会調査が「証拠に基づいて社会を語る道具」と呼ばれるのは、この点による。

!!! warning "「手続きの明示」と「同じ結果が出ること」は別"
    手続きを明示するのは、再現性を**検討できるようにする**ためであって、
    「同じ方法で調べれば必ず同じ結果になる」という意味ではない。
    同じ質問を同じ方法で尋ねても、時期や対象者が違えば回答は変わりうる。
    逆に、**偏った方法を繰り返せば、同じように偏った結果が何度でも出る**。
    「再現した」だけでは、その調査が正しいことの保証にはならない。

日常的な調べ物（Googleで検索する、友人に聞く）との違いも同じところにある。日常の目的は「自分が知りたいことを知ること」だが、社会調査の目的は「**社会的事実を明らかにし、共有すること**」である。共有するからこそ、倫理・方法・報告に一定の基準が求められる。

### 誰が、何のために使っているか

- **政策・行政** … 国勢調査、世論調査で人口・国民意識を把握し政策を立案する
- **ビジネス** … 市場調査・マーケティングリサーチで消費者ニーズをつかむ（→ 第6回）
- **研究・学術** … 社会問題の実態解明、理論の検証
- **市民社会** … NPOによる生活困窮者調査、地域ニーズの把握

### いま「読む側」の力が問われている

近年、調査そのものの信頼性が揺らぐ出来事が続いた。

- 調査結果の**恣意的な利用**（都合のよいデータだけを強調する）
- **標本の偏り**（誰に依頼し、誰が実際に答えたのかが確認できない調査がある）
- **統計不正問題**（厚生労働省・毎月勤労統計調査、2018年）
- メディアによる調査結果の**誤読**

!!! note "「ネットだから駄目」ではない"
    インターネット調査とひとことで言っても中身は違う。
    **無作為抽出した対象者にオンラインで答えてもらう調査**もあれば、
    **登録モニターやSNSで募った人に答えてもらう調査**もある。前者と後者では、
    結果を社会全体に当てはめてよいかがまったく変わる。
    見るべきは回線ではなく、**誰に回答を依頼し、誰が実際に回答したのか**である。
    これは紙の調査でも同じで、回収率が低ければ同じ問題が起きる。

だから、この授業で身につけるのは調査を実施する力だけではない。①調査結果を**批判的に読む**力、②調査を**自分で設計・実施する**基礎力、③調査に伴う**倫理的責任**の理解、の3つである。

### 身近な調査の例

| 例 | 実施主体 | 特徴 |
|---|---|---|
| 国勢調査 | 総務省統計局 | 5年に1回（直近2025年）。**日本に常住する**人と世帯が対象の**全数調査**（外国人を含む） |
| 世論調査 | 内閣府大臣官房政府広報室 | 無作為抽出で選んだ対象者に意識・意見を尋ねる。**近年は郵送法**で実施 |
| マーケティングリサーチ | 企業 | 新商品開発、SNSトレンド分析、CS調査（→ 第6回） |
| 学術研究 | 研究者 | ひとり親家庭の生活困難、若者の政治参加、外国人住民の労働環境など |

!!! note "「誰を選ぶか」と「どう集めるか」は別の話"
    **無作為抽出**は対象者の**選び方**、**郵送・面接・インターネット**は回答の**集め方**である。
    この2つは独立していて、組み合わせは自由に変わる。
    内閣府の世論調査は長く個別訪問面接法を基本としてきたが、新型コロナへの対応で
    **令和2年度以降は郵送法**に変わり、令和3年度以降は一部の調査で郵送・インターネットの
    どちらでも回答できる。対象者の条件や方法は**調査ごとに調査概要で確認する**こと。
    （選び方＝第10回、集め方＝第11・12回で詳しく扱う）
